# Certificate-Management
Webanwendung zur Verwaltung von Zertifikaten: Dashboard, Inventar, selbstsignierte Zertifikate und interne CA, Import/Export, Aufgaben mit Genehmigung, Discovery, Audit, Rollen und ein vollständiges Benachrichtigungssystem (E-Mail/SMTP und Telegram). Die Oberfläche ist zweisprachig (Deutsch/Englisch) und hat einen hellen und dunklen Modus.
